# C2 训练/部署架构草图（2026-10-23）

## 问题

Part1 是 8 障碍整场（手动遥控计分），Part2 是 6 类能力项（仅 RL，每类最多 4 次、按最高成功难度计分）。
参考轨迹是**每个任务一段**；需要明确：这些段要不要闭合、是否连成一条整场轨迹自动走完、以及一个模型还是多个模型。

## 建议架构

```text
高电平调度/状态机（非学习，任务选择与切换）
        │  选择任务 ID、起点、参考轨迹段
        ▼
低电平 RL locomotion policy（先一个多任务模型）
        │  观测: proprio + 速度指令/参考位姿误差 + phase/task embedding
        ▼
机器人关节动作
```

1. **参考轨迹按任务分段**，不要求闭合。每段有明确 entry port（任务起点/出发区）和 exit port（完成/离开点）。
2. **Part2 评估本来就是逐项独立**（每类 4 次，不是一条连续赛道），所以部署时状态机一次选一个类别：
   `选类别 → 放到该类别起点 → 跟踪该段 reference → 成功/失败/次数用尽 → 换下一个类别`。
   段与段之间不需要连成一条连续可跑轨迹；若某天要做“全能力场连续 demo”，用 flat connector 段把 exit port 接到下一个 entry port 即可。
3. **Part1 是手动遥控**，不需要整场自动轨迹；课程 loop 只用于说明/诊断/操作手参考。若以后做自动 Part1，
   同样用 route graph：每个障碍 entry/exit + 平地 connector 段拼接，可选闭环用于连续训练，而不是一条开环大轨迹。
4. **先训一个多任务模型**：混合 flat + 六类低/中 level，episode 从任务 entry 开始、到任务 exit 终止；
   观测里带任务/参考条件。优点：共享步态、样本效率高、部署简单。
5. **若单模型学不出高难度项**（45° 坡/40 cm 墙/30 cm 沟/梅花桩）：fine-tune 专项策略，状态机在部署时选择 RL 策略；
   这不是“固定动作”，Part2 规则允许。
6. **是否需要闭合轨迹**：
   - Part2：不需要；
   - 训练：不需要；episode 独立采样各任务段即可；
   - 全课程连续评估/演示：可选地用 connector 拼接成闭环，属于后续集成，不阻塞当前训练。

## 与 judge/C2 baseline 的关系

- 训练 reward 用仿真物理量 + 参考跟踪/进度/约束，**不依赖 judge**；
- judge 只用于 C2 评测/诊断和最终分数；C1 已完成，G1 暂不冻结（用户决策 A）。
- 统一模型/专项模型的选择由 smoke 结果决定，不改变 judge 协议。
