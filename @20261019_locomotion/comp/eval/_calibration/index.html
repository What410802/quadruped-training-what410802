按 scratch3.csv 逐条标注；视频/图在 ../prep.d/videos/calibration/。 judge verdict 未显示（盲标）。标注完成后运行 pixi run python @20261019_locomotion/scripts/agent_scripts/check_calibration.py。

失败原因字典（human_failure_reason）

取值定义
fell机器人翻倒/侧翻/明显失稳，已无法继续（最高优先级）
bar_drop限高杆被顶落到低位（横杆掉落）
two_feet_ground明显 ≥2 足同时触地而仍在障碍上（非完成跨越后的落地）
wrong_side从错误一侧进入/退出（如砂砾坑应从短边进）
incomplete明显只完成一部分（T 台阶单臂、桥走到一半、台阶缺级等）
no_crossing保持站立但没完成障碍：停住/卡住/走偏/最终没越过
timeout视频在完成前结束（4–6 s 截断），无法判断后续；不是官方 120 s 超时
other:<说明>以上都不合适

rulecard 怎么看

每张 SVG 含：俯视几何脚印 + 路径/足端 tag + base/bar 高度曲线 + judge evidence + KEY RULE 差异点。 不要只看足端 tag；按 KEY RULE 的判据判断"应 success/fail"，再判 judge 是否正确。

session_state

8 条是协议/账本状态表（没有机器人视频），判断 best score/同分最快/恢复不消耗/暂停冻结/abort/skip 等语义是否正确即可。
