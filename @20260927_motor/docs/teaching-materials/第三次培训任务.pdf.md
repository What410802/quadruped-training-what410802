# 第三次培训任务

本次任务分两部分：

## 一、仿真部分

仿真添加控制程序，控制程序仿真模拟关节电机的特性控制电机，控制程序需要写成状态机，包含两个状态：
1. 阻尼模式，所有关节电机均是阻尼状态。
2. 站立模式，阻尼模式下，按下键盘上的某个键就能让狗站起来（从任意初始位置，差值，连续地站起来）。按下另外一个按键，就能又切换回阻尼模式。

## 二、实体电机控制

1. 先尝试使用宇树官方电机sdk例程让电机转起来。
2. 书写控制程序达到以下功能：让电机慢慢回归0位置，然后键盘输入一个角度，输出端就能缓慢转到那个角度。
3. 用记号笔或者贴纸记下2步骤中的零点，然后使用课程视频中讲的方法将零点正向偏移30度，然后重新让电机转到2步骤中你指定的那个角度，看看电机的角度和终端输出的电机位置是否符合预期。（上电前需要先自己确定零点未跳变。或者，你可以先完成4，再来完成3）
4. 在3的基础上尝试使用课程视频中讲的方法处理零点跳变问题。以达到将电机输出端手动转到2中零点的附近（零点之前和之后都要尝试），然后让电机转到3步骤的那个位置，看看是否发生跳变。

上述电机转动任务请提前做好保护，利用插值使得电机缓慢转动，请使用大疆电池，小白接线请求助四足/电控老队员。
