# 板子的控制环与实机误差来源（MIT / FOC）

> 这份文档回答两个问题：**我们发出的 5 个量进了驱动板之后发生了什么**（板子里跑的控制律），以及**实机停稳时 ±0.05° 的偏差从哪来**（2026-10-01 三组实机数据的分析）。
> 接口边界（哪些量下发、哪些参数归我们）在 [design.md](design.md) §3.3；报文标度与实机锚点在旧版 [protocol.md](../../cpp_part2/docs/protocol.md) 与 [fixed-point.md](../../cpp_part2/docs/fixed-point.md)；本文引用的数据文件在 [`../../output/terminal/`](../../output/terminal/)（`motor-real-202610011135 / 1202 / 1210-m1-ctl.txt`）。

## 1 一条命令的三层：我们 → 驱动板 → FOC → 电机

我们只跟"驱动板"打交道；板子内部还有一层电流环，我们既看不到也不需要知道：

```text
我们的程序（~5 ms/帧）        驱动板固件                          电机
  5 个量（位置/速度/力矩/kp/kd）──▶ MIT 位置环（板内连续运行、远快于我们）
                                    τ = τ_ff + kp·(p_des − p) + kd·(ω_des − ω)
                                        │
                                        ▼
                                    FOC 电流环（换向 + 电流闭环）
                                        │
                                        ▼
                                     三相电流 → 电磁力矩
```

1. **我们这一层**负责"去哪、多软、多快"：位置目标由梯形插值给出（[trajectory.hpp](../core/include/motor/trajectory.hpp)），增益按输出端配置、÷N² 后下发（[design.md](design.md) §3.3）。
2. **驱动板的 MIT 混合控制**是一个持续运行的"弹簧 + 阻尼器 + 恒力源"：不管我们发不发新命令，它每个控制周期都在按公式出力——这就是"断链后驱动板仍执行最后一条指令"的原因（S2e 实测，见旧版 [real.md](../../cpp_part2/docs/real.md) §3.7）。
3. **FOC（磁场定向控制）**把"想要的力矩"翻译成三相电流：它负责换向与电流闭环，让"要多少力矩给多少"在小力矩以外近似成立；它的边界（电流限幅、母线电压、反电动势）就是转矩-转速曲线的由来。实机日志里读到的 `tau` 已经是板子解算后的力矩估计，不是我们的指令。

## 2 为什么"给多少出多少"不是白来的（讲义 §1.1）

真实电机（含驱动板）的力矩传递有三段非线性，讲义 §1.1 的图就是它：

| 区 | 表现 | 原因 |
|---|---|---|
| 小力矩死区 | 指令很小时输出被摩擦吃掉 | 减速器 / 轴承的静摩擦 |
| 近似线性区 | 指令 ≈ 输出 | 电流环正常工作 |
| 饱和 / 降额 | 大力矩被限幅；高速时可用力矩随转速下降 | 电流限幅 / 母线电压与反电动势 |

仿真里我们按"理想力矩源 + 限幅 + 库仑摩擦 + 最高转速"建模（[design.md](design.md) §3.7）。本次实机数据验证的正是**第一段**：静摩擦死区——它不体现在"指令力矩"，而体现在**位置环停稳后的静态偏差**里。

## 3 实机数据：停稳偏差的 8 次采样

三次运行、两组增益（kp=80 与 kp=320），每次停到一个目标、取停稳后的读数（`帧` 行的 q 与目标之差）：

| 数据文件 | kp（输出端） | 目标 | 逼近方向 | 停稳读数 | 偏差（计数） |
|---|---|---|---|---|---|
| 1135 | 80 | 0.000° | 正向回零 | +0.045° | +26 |
| 1135 | 80 | 30.000° | 从下 | +30.055° | +32 |
| 1202 | 80 | 40.000° | 从下 | +39.955° | −26 |
| 1202 | 80 | 44.999° | 从下 | +44.930° | −40 |
| 1202 | 80 | 40.000° | 从上 | +39.990° | −6 |
| 1210 | 320 | 80.000° | 从下 | +79.990° | −6 |
| 1210 | 320 | 84.999° | 从下 | +85.025° | +15 |
| 1210 | 320 | 80.000° | 从上 | +80.011° | +6 |

1 计数 = 0.0017347°（输出端）。把偏差乘回转子的弹簧刚度 `K_P = kp_out / N²`（kp=80 → 1.9945、kp=320 → 7.978 N·m/rad），得到"位置环为了顶住阻力而静差出的力矩"：

| kp=80 | kp=320 |
|---|---|
| +9.9、+12.2、−10.1、−15.2、−2.2（×10⁻³ N·m） | −8.9、+22.9、+9.6（×10⁻³ N·m） |

> 为什么不用日志里的 `tau` 直接看阻力？它的分辨率是 1 LSB = 1/256 N·m（转子侧）≈ **0.0247 N·m（输出端）**，而这个量级的阻力只有 2–3 个 LSB——读不出来。所以本文用"位置偏差 × K_P"反推，精度好得多。

## 4 结论（以及边界）

1. **不是换算 / 标定错误**：若偏差来自减速比或 π′（比例误差），目标 0° 处应当为 0；实测 0° 处同样有 +26 计数 ⇒ 是**绝对量**（另有量化，只有 ±1 计数 = 0.0017°，可忽略）。
2. **不是固件零偏**：同一 kp 下偏差正负都出现过（1202 两次"从下逼近"：−26 与 −40；1210 两次"从下逼近"：−6 与 +15）⇒ 停点不可复现、符号会变，符合**静摩擦的粘滑（stick-slip）**特征。
3. **量级 = τ_f / kp**：位置环停在"弹簧力顶住阻力"处，偏差上界约 `τ_f/K_P`。实测等效保持力矩 |τ| ≤ 0.023 N·m（转子侧，≈0.14 N·m 输出端）；典型 ±26 计数（kp=80）对应 τ ≈ 0.010 N·m。
4. **kp ×4 ⇒ 偏差包络约 ÷4**：kp=80 时 |偏差| ≤ 0.07°，kp=320 时 ≤ 0.03°。这是"要更准就加大 kp"的定量依据（也要留意 kp 大了更硬、冲击与噪声更敏感）。
5. **诚实边界**：τ_f 的精确值、以及是否存在一个小常数外力（拖线 / 悬臂重力），这 8 个点分辨不了（停点随机性盖过了它）。要分清得按 §5 补测。
6. **对验收的意义**：任务书要求 ±1°，实测偏差（≤0.07°）远小于它；记录表里的"微小偏差"可据此解释为静摩擦死区，并注明"加大 kp 可缩小"。
7. **对仿真的意义**：实验台模型的摩擦默认值按本次数据定为 `τ_f = 0.010 N·m`（[model.hpp](../sim/include/motor_sim/model.hpp)），使离线演练在 kp=80 时复现同量级的 ±26 计数死区。

## 5 复现与排查（下次怎么用）

| 想确认什么 | 怎么做 | 判据 |
|---|---|---|
| 是不是比例（标定）误差 | 在 0° 附近与 60° 附近各停一次 | 0° 处也有偏差 ⇒ 不是比例 |
| 是不是固件零偏 | 同一目标、同一方向重复 5 次以上 | 偏差总同号、且不随 kp 缩小 ⇒ 零偏 |
| 是不是摩擦死区 | 把 kp 乘 4 再测 | 偏差包络按 1/kp 缩小 ⇒ 摩擦 |
| 有没有恒定外力 | 正、反两个方向各多测几次 | 偏差分布整体偏向一侧 ⇒ 有外力 |

（本次只有 8 个点，上表后三行的严格结论需要按"重复 + 双向 + 变 kp"补测；这也是 M4 记录表可以顺手收集的数据。）
