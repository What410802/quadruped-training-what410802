# 实机执行卡（M1 在线简版）

> 本卡只覆盖 M1 的范围：任务书 ②（回编码器零点、键盘给角度）与 ③（记号笔标记、零点正向偏移 30°）的主干。
> 假设"程序运行时段 ⊆ 电机上电时段"：不做断线恢复、不做认错零点修正、不脚本化（这些按 [design.md](design.md) §6 在 M3–M5 加）。
> 安全与接线的完整清单在旧版 [`../../../cpp_part2/docs/runbook.md`](../../../cpp_part2/docs/runbook.md) §2 批次 0，本卡只列要点。

## 1 前置（要点）

- 电机夹紧固定；输出端没有会甩出去的线；手能随时断电。
- 接线问老队员（转接头 TTL / RS485、几根线、共地），确认电机 ID。
- 大疆电池供电；USB 只供通信。
- 权限：`sudo`，或 `usermod -aG dialout` 后重新登录。
- 上电前把输出端摆到**同一个物理位置附近**（四足上的对应约定是"先摆成趴卧"）：目的是让板子选中的候选零点尽量一致；注意这说的是物理位置，不是"读数一定落在同一个候选零点"。

## 2 命令与日志

```bash
cd <仓库路径>                                    # 换成你的仓库根目录（MyMonoRepo.d/ 那一级）
pixi run cmake -S @20260927_motor/cpp_part2_remake -B @20260927_motor/cpp_part2_remake/build
pixi run cmake --build @20260927_motor/cpp_part2_remake/build

T=<仓库路径>/@20260927_motor/cpp_part2_remake/build/tests/motor_core_tests
B=<仓库路径>/@20260927_motor/cpp_part2_remake/build/apps/motor_ctl/motor_ctl
$T                                               # 先过核心自检（不接电机）
$B --no-send                                     # 看配置，不开串口

sudo @20260927_motor/scripts/run_log.sh m1-ctl $B --port /dev/ttyUSB0 --id 0   # 交互；日志自动落到 output/terminal/
```

交互（终端里）运行时，最后一行固定为输入行（`> ` 提示符），状态输出不会把它冲散；退格 / `Ctrl-U` 编辑、`Ctrl-D` 或 `quit` 退出、`Ctrl-C` 正常卸力退出。脚本模式（重定向 stdin）行为不变。

脚本形态（无人值守，最后 `quit` 卸力）：

```bash
sudo $B --port /dev/ttyUSB0 <<< "move 0; wait 3; mark; move 30; wait 3; zero move 30; state; move 30; wait 3; quit"
```

角度输入默认度，可加 `deg` / `rad` / `r` / `rev` / `tick`（`tick` = 转子计数）；显示一律是"±圈数 ±<360°"。

## 3 步骤卡

| # | 做什么 | 命令 | 期望看到 |
|---|---|---|---|
| 1 | 启动 | （见 §2） | 打印配置；`启动：板子读数 raw …（+0 圈 +X°）—— 距本次上电基准的编码器零点` |
| 2 | 看账本 | `state` | `turn_base +0`、`offset +0`（默认值）；事件 1 条"上电锚定" |
| 3 | ② 回零 | `move 0` | 通常**反向**转一小段（≤ 一个零点区间 56.84°）后停下；帧行 `q +0 圈 +0.000°` 附近，最后打印"⇒ 到位" |
| 4 | 打记号笔 + `mark` | （物理动作）+ `mark` | **就在这个位置**画线/贴纸，并**立刻 `mark`**——软件标记点与物理标记都在零点（③④ 的物理基准）；提示会打印"离零点边界"，最好 ≥10° |
| 5 | ② 给角度 | `move 30` | 平滑转到 30°（按 vmax 90°/s 约 0.7 s），`⇒ 到位`；读数 `+0 圈 +30.000°` 附近（抄进 §4） |
| 6 | （可选）验证标记 | `mark goto` | 回到标记点（验证软件记录与物理标记一致），到位后再 `state` 看一眼 |
| 7 | ③ 移零点 | `zero move 30` | 电机**不动**；零点沿正方向移动 30°（内部 offset 变成 −17294 计数 = −30.000°）；提示里会打印"标记点读数 −30.000°" |
| 8 | ③ 复查 | `state` | 同一物理点（标记处）读数应为 **−30.000°** 附近 |
| 9 | ③ 回原角度 | `move 30` | 同一个角度命令的落点比标定前**多 30°**（板子目标 = +60°，零点往前挪了）；终端读数仍是 +30.000° 附近 |
| 10 | 收尾 | `quit` | 先发 20 帧零力矩，打印汇总；再断电 |

手动搬动电机只在 `free`（零力矩）下发；带位置环时手只能把它推开几度。

| `move 30` 到位后的 q | |
| `zero move 30` 后的 offset 与标记点读数 | |
| `move 30` 复跑的落点（比标定前多 30°） | |
| 汇总行：帧数 / 超时 / 力矩峰值 / 温度峰值 / 事件数 | |

停稳后可见 ±0.05° 量级的固定偏差，来源是**静摩擦死区**（上界 ≈ `τ_f/K_P`，加大 kp 可缩小）；判据、8 次实测数据与补测方法见 [control-loop.md](../control-loop.md)。

## 5 异常与退出码

| 现象 | 退出码 | 处置 |
|---|---|---|
| 启动 2 s 内一帧回复都没有 | 3 | 查 ID、接线（TX/RX/共地）、供电、权限 |
| 保护触发（`merror` / 超温 / 力矩持续超限判卡住） | 4 | 看原因行；`merror` 非 0 就断电检查 |
| 打开串口失败 | 2 | 看 SDK 异常原文（设备不存在 / 不在 dialout 组） |
| 想立刻停 | — | `Ctrl-C`（程序会先卸力退出，退出码 130）；不行就断电 |
| 连续 40 帧无回复 | 4 | M1 是"报警退出"；断线恢复属 M3 |

## 6 本次不覆盖

- 断电重上电 / 手转跨零点 / 认错零点修正（M3–M4，属任务书 ④）；
- 新版探针与旋转工具（M2c；先要 S2 的话用旧版 [`../../../cpp_part2/docs/runbook.md`](../../../cpp_part2/docs/runbook.md) 批次 3 的 `serial_probe`）。

## 7 虚拟实验台（无实机时先演练 M1 主干）

两个终端，一个跑实验台（假电机），一个跑 `motor_ctl`（走**真实 SDK**，不需要 sudo）：

```bash
B=<仓库路径>/@20260927_motor/cpp_part2_remake/build    # <仓库路径> 换成你的仓库根目录

# 终端 2：实验台
$B/apps/motor_sim/motor_sim
```

终端 2 启动时会打印一行**可直接复制**的命令（已含本机实际的 PTY 路径与垫片路径），粘到终端 1 执行即可：

```bash
LD_PRELOAD=<...>/libpty_serial_shim.so <...>/motor_ctl --port /dev/pts/N
```

格式固定是 `LD_PRELOAD=<垫片> <motor_ctl> --port <PTY slave>`。**`/dev/pts/N` 每次都不一样，必须用终端 2 打印的那个**——机器上每个终端自己就是一个 `/dev/pts/N`，填错会连到别的终端（现象：控制程序收不到回复、被填的终端刷乱码）。

实验台的 REPL：`status` / `torque <N·m>` / `hold [<角度>]` / `release` / `line draw|angle|clear` / `wait <秒>` / `help` / `quit`；启动参数 `--print-interval <秒>`（周期打印间隔，0 = 关闭；日志更干净）、`--frame-period <秒>`（空闲推进步长）。

| 步 | 终端 2（实验台） | 终端 1（motor_ctl） | 期望 |
|---|---|---|---|
| 1 | 启动，记下 slave 路径 | 启动（见上） | 控制程序打印"距编码器零点 X°"；实验台开始有帧计数 |
| 2 | `line draw`（可选：把线画在 `move 0` 之后） | `move 0` → `mark`（**打标记**） | 到位；线夹角 ≈ 0° |
| 3 | — | `move 30` | 平滑到位；线夹角 ≈ 30° |
| 4 | `line angle` | `zero move 30` → `state` | 电机**不动**（线夹角不变），终端 1 的 q 变 **−30.000°**（标记点读数） |
| 5 | `line angle` | `move 30` | 电机落到**线前方 60°**（同一个命令比标定前多转 30°）；要回线上用 `move -30`（标记点当前读数） |
| 6 | `hold 60`（模拟手把它扳到 60°） | `free` 后观察 `state` | 位置真值变化；再 `hold` 收回 |
| 7 | — | `quit` | 先卸力再退出；实验台会看到超时（正常） |

注意：实验台是"设备进程"，`quit` 或 `Ctrl-C` 才退出；控制程序退出后它**继续执行最后一条指令**（与实机 S2e 一致）。
